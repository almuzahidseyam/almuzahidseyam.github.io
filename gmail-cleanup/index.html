n8n Gmail Cleanup Personal

A personal workflow operated by Muhammad Al-Muzahid to keep his own Gmail account manageable. It checks old email from reviewed marketing senders and clearly promotional bulk streams, then moves eligible messages to Trash.

Personal use only. This is documentation for the owner’s local automation. This website does not offer Gmail sign-in, connect visitors’ accounts, or display mailbox data.

How cleanup works

The local n8n workflow runs once per Asia/Dhaka calendar day while the owner’s computer is awake. It checks when n8n starts and every 15 minutes, and skips further cleanup after a successful run that day. Bounded scans save their next page locally, so later daily runs can continue through older messages. It considers messages at least 30 days old from reviewed senders. Other bulk messages can qualify only in Promotions, Social or Spam when a marketing-style sender address, bulk-mail headers and an explicitly promotional subject all agree. Read and unread messages must pass the same preservation rules.

Careful selection

Starred, important, custom-labeled, attachment-bearing and conversational messages are preserved. Unlisted senders outside the strict promotional rule remain for review. Unread messages must pass the same importance checks. Rules also preserve messages with potentially important financial, security, education, career and transactional signals.

What changes in Gmail

Only individual messages that pass all selection checks are moved to Trash. The workflow does not permanently delete mail. Gmail normally permanently deletes messages after 30 days in Trash; the owner can restore them before then.

Classification uses conservative rules, rather than an AI service. Ambiguous messages are kept. These rules reduce mistakes but cannot guarantee perfect judgment; the owner should review Trash and adjust the policy when needed.

Google access

The owner authorizes the local application through Google OAuth with the gmail.modify scope. This permission allows reading and modifying email and also permits composing and sending mail. The configured workflow uses it only to check the account, read message metadata and move selected messages to Trash.

The workflow checks the connected account before processing and stops if it is not the owner’s configured account. Mail processing runs locally; this public website is separate from n8n.
