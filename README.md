# almuzahidseyam.github.io redirect

This folder redirects `https://almuzahidseyam.github.io/` to `https://muhammad-almuzahid.web.app/` and preserves paths, query strings and URL fragments.

## Publish

1. Sign in to GitHub using the `almuzahidseyam` account.
2. Create a **public** repository named exactly `almuzahidseyam.github.io`.
3. Upload `index.html`, `404.html` and `.nojekyll` from this folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then save.
7. Open `https://almuzahidseyam.github.io/` after GitHub finishes deployment.

To change the destination later, replace `https://muhammad-almuzahid.web.app/` in both HTML files.
